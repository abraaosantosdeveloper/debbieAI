# Debbie AI — Projeto de Geração Aumentada por Recuperação (RAG)

Este projeto é um pequeno exercício de desenvolvimento de Agentes de IA que resolvi criar para consolidar e provar meus conhecimentos. Não é, nem de longe, mais uma plataforma de IA emergente ou algo parecido, embora eu planeje incorporar algum modelo conversacional para que o app seja um pouco mais completo. Contudo, uma vez que a proposta é consolidar conhecimentos em RAG, as primeiras versões serão extremamente enxutas.
